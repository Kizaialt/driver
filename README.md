# Peaklab — Драйверын хуудас

Нэг хуудаснаас бүх драйвер.

**<https://kizaialt.github.io/driver/>**

Хэрэглэгч загвараа хайгаад драйвераа шууд авна. Долоон загвар монгол хэлтэй,
бусад бүх загварт үйлдвэрлэгчийн албан ёсны драйвер руу холбоно — хэн ч
хоосон буцахгүй.

---

## Юу байгаа вэ

| | Тоо | Юу болох |
|---|---|---|
| **Монгол хэлтэй** | 8 | Peaklab-ийн орчуулсан драйвер |
| **Бусад загвар** | 38 | Үйлдвэрлэгчийн драйвер руу шууд холбоос |

### Монгол хэлтэй загварууд

| Загвар | Хэрхэн |
|---|---|
| AULA WIN 60 HE / WIN 68 HE | [Онлайн драйвер](https://kizaialt.github.io/winhe-driver/) — суулгах шаардлагагүй |
| AULA F65 / F75 / F99 / F108 | Үйлдвэрлэгчийн драйвер + [монгол багц](https://github.com/Kizaialt/aula-fseries-mn) |
| KYSONA M600 / M600 V2 | Үйлдвэрлэгчийн драйвер + [монгол багц](https://github.com/Kizaialt/kysona-m600-mn) |

M617, Aztec загварууд M600-ын драйвер ашигладаг тул мөн ажиллана.

## Бүтэц

```
index.html                 ← үүсгэгддэг файл. Гараар засахгүй.
src/index.template.html    хуудасны загвар (HTML + CSS)
src/filter.js              хайлтын скрипт (бусад бүх зүйл build дээр бэлдэгддэг)
data/models.json           загваруудын жагсаалт
tools/
  catalogue.py             үйлдвэрлэгчийн жагсаалтаас models.json үүсгэх
  build.py                 template + models.json → index.html
  checklinks.py            бүх холбоос ажиллаж байгааг шалгах
PRODUCT.md                 хэн, юуны тулд ашигладаг вэ
```

### Дахин үүсгэх

```bash
python tools/catalogue.py   # загваруудын жагсаалтыг шинэчлэх
python tools/build.py       # index.html үүсгэх
python tools/checklinks.py  # холбоосууд ажиллаж байгаа эсэхийг шалгах
```

`index.html` нь **build дээр бүрэн бэлдэгддэг** — 46 загвар бүгд HTML дотор
бичигдсэн байна. JavaScript зөвхөн хайлт хийдэг (2.6 КБ). Тиймээс:

- JavaScript унтраалттай байсан ч бүх загвар харагдана
- Эхний харагдалт скрипт хүлээхгүй
- Хайлтын системд индексжинэ

## Засвар оруулах

**Шинэ загвар нэмэх / орчуулга нэмэгдэх үед:** `tools/catalogue.py` доторх
`MONGOLIAN` жагсаалтад нэмээд дахин build хийнэ.

**Үйлдвэрлэгч драйвераа шинэчилбэл:** `tools/aula_links.json`-г шинэчлээд
`catalogue.py` ажиллуулна.

**Push хийхийн өмнө `checklinks.py` ажиллуулаарай.** Үйлдвэрлэгчийн татах
холбоосууд нь токентой query string тул хамгийн эмзэг хэсэг нь тэр.

## Анхаарах зүйл

- Монгол хэлний багцууд **жинхэнэ төхөөрөмж дээр хараахан туршигдаагүй**.
  Хуудсан дээр үүнийг ил бичсэн.
- Драйверын программууд AULA, KYSONA-гийнх. Бид зөвхөн хэлний файл нэмсэн.
- `?` тэмдэгтэй холбоосуудыг (AULA-гийн татах линк) хугацаа өнгөрөхөд
  ажиллахаа болих магадлалтай — тиймээс `checklinks.py` байгаа.
